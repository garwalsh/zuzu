The problem

Why this matters

USCIS forms are long, in English, and one wrong box costs months.

  • →They are hardest for exactly the people the system already fails: disabled, elderly, low-literacy, and non-English-speaking applicants.
  • →The alternative is a lawyer at roughly $2,000, or filing alone and hoping.A rejected filing is not a retry. It is months of waiting, and sometimes a status that lapses in between.
  • →The information is not the hard part. The form is.

Part 2

How a call works

Orchestrator-driven

The applicant says “I need my work permit” — never “I-765”. The voice agent knows nothing about any specific form; it asks what the orchestrator hands it.

01Listen ElevenLabs, in the caller’s own language
02Identify Plain words or a pasted URL → the right form
03Ask One question at a time, read back for confirmation
04Fill The official AcroForm PDF
05Hand over Completed form plus the documents to attach
Answer stored in0.03 ms
Model on the live pathNone

A human is mid-sentence while those endpoints run, so nothing slow is allowed on that path. Mapping and PDF work happen off it.

All three are on screen during the call, counts included. They are stored separately, so an applicant can delete their call history and keep the profile that saves them an hour. Sensitive values are not persisted unless explicitly opted in, and the store is keyed by a hash — never a raw phone number.

Field names are extracted, never recalled by a model. A hallucinated field name is an application that silently loses half your answers — so the model only writes the wording, and every reference is validated back against the real document.

Part 6

Six agents, talking to each other

Band · MiniMax-M3
IntakeThe conversation What to ask next, and when it is done
ExtractorProvenance Where each value came from
MapperPlacement Onto this form’s fields
ValidatorCross-checks What no single field can show
FillerThe PDF Refuses on a blocking finding
AuditorThe record Sealed, per application

Each holds its own Band WebSocket under its own per-agent key and addresses the others by mention. Each decides for itself what to do next — MiniMax-M3, given Band’s own tool schemas. The model chooses who acts next; every applicant value, every check and every byte of the PDF comes from a deterministic tool.

In a legal-filing domain the trail is the product. Every turn records the tools it ran, who it addressed, and which of the two decided it — the model, or the deterministic fallback that takes over when the model cannot be reached.

  • ✓Arrival in the U.S. dated before the date of birth
  • ✓A student category with no SEVIS number The most common avoidable I-765 rejection.
  • ✓A value that will overflow its printed box — measured on what actually gets writtenA validator that cries wolf is worse than no validator.

The stack

What each one actually does
ToolJob
ElevenLabsThe whole interface. Five server tools; knows no specific form.
SupabaseSemantic, episodic and procedural memory in Postgres, keyed by a hash of tenant and caller. Row level security denies everything but the service key.
rtrvr.aiReads uscis.gov, which returns 403 to scripted requests. 17 live document requirements.
RocketRidePipeline-as-JSON for form intake and model selection — config is the source of truth.
TokenRouterMiniMax, routed inside that pipeline. Spoken-value normalisation and translation.
BandThe agents' actual transport. Six external agents, each on its own WebSocket, addressing each other by Band mention. Band's own tools are offered to the model alongside ours.
RenderOne blueprint, one live URL.

Prompt Driven Development throughout: prompts are source, api/ is output, and architecture.json declares the module graph.

Part 8

What we are not claiming

Stated before you ask
Verified · not overstated
  • —Cerebras. The account returns 402 Payment Required and the model our docs named does not exist on it. It never ran, so we do not submit that track. The inference lane is provider-agnostic, so it is a config flip if credits arrive.
  • —Band chat, the human side. Agents open rooms and address each other over Band's Agent API, which works on the free plan. The Human API -- a person reading those rooms through the API -- answers 403 plan_required and needs Enterprise. Band's own memory tools are gated the same way: ff_memory is false on Free, so the three tiers are ours, in Postgres.
  • —Fully emergent routing. An agent chooses who to address, and does so over Band. But when it declares its own part finished, the fixed role order picks who goes next — not its choice. So: the agents decide, within an order that still has a floor.
  • —Email delivery. The RocketRide pipeline runs, but Gmail has no credentials configured, so nothing is sent — and the code returns delivered: false rather than a green tick nobody can find in an inbox.
  • —All-generated code. Two of ten modules came from pdd --local generate; the rest are hand-written to the same prompts. The README says so, per module.
